# 薪资跳动（Salary Pulse）设计规格

日期：2026-09-02
状态：待用户审阅（视觉风格由用户在 Stitch 中生成定稿，本规格只约定功能
与行为）

## 1. 目标与非目标

**一句话**：一个纯前端网页，让打工人在上班时间看着「今日已赚」的金额每秒
往上涨，行情式跳动，攒出上班的获得感。

**目标**
- 单屏实时赚钱计数器：工作时间内金额持续跳动，下班后按加班倍率继续
- 展示：今日已赚（主数字）、每秒费率、本月累计、今年累计、今日加班费、
  下班倒计时
- 支持月薪制与年薪总包制两种计薪口径
- 视觉风格不在此约定：由用户拿「页面清单.md」在 Stitch 生成后定稿
- 纯静态部署：Vite + Vue 3 + TypeScript，`npm run build` 产物可托管任意
  静态服务或 GitHub Pages；配置存 localStorage

**非目标（v1 明确不做）**
- 后端、账号、云同步（换设备需重新填写配置，约 1 分钟）
- 法定节假日/调休日历（按周一~周五处理；计算模块预留节假日表扩展点）
- 周末加班计费（周末金额不跳）
- 涨薪历程记录、多配置档案
- 税后精确计算（按填写的税前口径直接折算）

## 2. 核心计算模型

所有金额计算是 `src/lib/calc/` 下的纯函数，无任何副作用，由绝对时间推导，
**绝不累加**——页面显示只是对推导结果的刷新，因此关页面、改系统时间、
跨设备重开都不会漂移。

### 2.1 配置（Config）

```ts
interface Config {
  payMode: 'monthly' | 'annual'   // 月薪 / 年薪总包
  amount: number                  // 月薪（元）或年薪总包（元），> 0
  workStart: string               // "HH:mm"，默认 "09:00"
  lunchStart: string              // "HH:mm"，默认 "12:00"
  lunchEnd: string                // "HH:mm"，默认 "13:00"
  workEnd: string                 // "HH:mm"，默认 "18:00"
  overtimeRate: number            // 加班倍率，默认 1.5，≥ 1
}
// 工作日固定为周一~周五（0=周日 … 6=周六，取 1..5）
```

校验规则：`workStart < lunchStart < lunchEnd < workEnd`（同日内）；
`amount > 0`；`overtimeRate ≥ 1`。任一不满足即视为无效配置。

### 2.2 每秒费率

- 每日有效工作秒数 `S = workEnd − workStart − (lunchEnd − lunchStart)`
- 月薪 M：`rate = M ÷ (21.75 × S)`（21.75 为劳动法月计薪天数）
- 年薪 A：`rate = A ÷ (261 × S)`（261 = 21.75 × 12）
- `rate` 单位为 元/秒，展示为 `+¥0.0341/秒`（保留 4 位小数）

### 2.3 核心函数 `earnedBetween(config, from, to)`

返回 `{ regular: number, overtime: number }`（单位：元，浮点，展示时才取整
到分）。算法：按天迭代 `[from, to]` 涉及的每个日期（浏览器本地时区）：

- 非工作日（周六/日）贡献为 0
- 工作日的正常窗口 = `[workStart, lunchStart] ∪ [lunchEnd, workEnd]`，
  与 `[from, to]` 求交，秒数 × rate → regular
- 工作日的加班窗口 = `[workEnd, 当日 24:00)`，与 `[from, to]` 求交，
  秒数 × rate × overtimeRate → overtime
- 所有窗口不重叠，无需去重

### 2.4 派生指标（全部由 earnedBetween 推导）

| 指标 | 定义 |
|---|---|
| 今日已赚（主数字） | `earnedBetween(今日00:00, now)` 的 regular + overtime |
| 今日加班费 | 同上拆分出的 overtime 部分 |
| 本月累计 | `earnedBetween(本月1日00:00, now)` 合计 |
| 今年累计 | `earnedBetween(今年1月1日00:00, now)` 合计 |
| 每秒费率 | 2.2 的 rate；加班中显示 `rate × overtimeRate` |

### 2.5 状态机（状态行徽章）

按 `now` 判定（均为本地时间）：

| 状态 | 条件 | 行为 |
|---|---|---|
| 未开盘 | 工作日、now < workStart | 徽章灰调 +「距开盘 HH:MM:SS」 |
| ●交易中 | 工作日、workStart ≤ now < lunchStart 或 lunchEnd ≤ now < workEnd | 徽章强调，主数字跳动 |
| 午间休市 | 工作日、午休时段内 | 数字暂停（午休不计薪） |
| ●加班中 | 工作日、now ≥ workEnd | 徽章强调，主数字按倍率继续跳，倒计时行显示「已加班 HH:MM:SS · ×1.5」 |
| 休市 | 周六/日 | 数字静止 |

下班倒计时：交易中/午间休市状态下显示「距下班 HH:MM:SS」，最后 1 小时
显著强调（强调样式以定稿视觉稿为准）。

## 3. 界面与行为

视觉由用户在 Stitch 出图后定稿（页面与功能清单见根目录「页面清单.md」），
本节只锁定功能行为：

- **两个视图**：主计数器页（默认）、设置页（首次无配置时强制进入）
- **主计数器页**：状态行（徽章+日期+齿轮）；「今日已赚」标签；超大主数字；
  费率与倒计时行；底部三列读数（本月累计｜今年累计｜今日加班费，
  加班中时该列高亮）
- **跳动行为**：主数字每 250ms 刷新；数字位变化动画与上涨反馈的视觉形式
  以定稿视觉稿为准
- **设置页**：计薪模式（月薪/年薪二选一）、金额、上下班时间、午休起止、
  加班倍率；保存时校验（2.1 规则），错误提示显示在字段下方；保存即写
  localStorage 并返回主页面
- **PWA（可选加分项）**：manifest + 极简 service worker（shell
  cache-first），仅在 http(s) 托管时生效；不为此引入复杂度

## 4. 数据与存储

- localStorage 键：`salary-pulse.config.v1`，值为 Config 的 JSON
- 读取时校验：损坏/缺失/非法 → 忽略并视为未配置，进入设置页引导
- 无其他持久化数据；版本号进键名，未来结构变更用新键迁移

## 5. 错误处理

- 未配置 → 强制设置页，提供「填入示例数据先看看效果」入口
- 表单校验错误逐字段提示（见 2.1 / 3）
- 系统时间被改动：无所谓——一切从绝对时间推导，显示自然跟随当前时间
- 主数字/费率计算出现 NaN（理论不可达）：显示 `¥0.00` 并在控制台告警

## 6. 测试与验收

**vitest，重点覆盖 `lib/calc` 纯函数**：
- 月薪与年薪两种费率推导（含 21.75 / 261 口径）
- earnedBetween：单日内各时段切片、跨午休、跨天、跨月、跨年、跨周末、
  `from > to`（返回 0）、from/to 落在窗口边界（含/不含端点）
- 状态机：五个状态各自的判定时刻
- 组件冒烟：挂载主页面（注入配置 + 假时钟）断言渲染文本；设置页校验
  规则的表单级测试

**验收标准**
1. 手工按 21.75 口径推算的「今日已赚」与页面一致（精确到分）
2. 关闭页面任意时长后重开，金额不漂移（等于按当前时间重算的结果）
3. 午休时段打开页面，数字静止；下班后打开，主数字按倍率跳、加班列红显
4. 清空 localStorage 后刷新，进入设置引导；填入示例数据后回到主页面
5. `npm run build` 产物本地静态服务可正常使用；移动端 375px 宽无横向
   滚动、主数字自适应

## 7. 技术栈与结构

- Vite + Vue 3 `<script setup>` + TypeScript + vitest
- 无 UI 组件库（视觉全部定制，组件手写）；无路由库（两视图用 v-if 切换）
- 目录：`src/{App.vue, SettingsView.vue, components/, lib/calc/, lib/storage.ts, styles/}`，
  测试 `tests/`
