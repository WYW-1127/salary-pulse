# 薪资跳动 (Salary Pulse)

给打工人的实时赚钱计数器：上班时间打开页面，看着「今日已赚」像水电表一样
一秒一秒往上涨。

![截图](docs/screenshot.png)

## 特性

- **滚轮计数器**：每个数位独立滚动的机械字轮，金额每 250ms 跳一次，
  进位时正向滚满一圈，绝不倒转
- **行情状态机**：未开盘 / ●交易中 / 午间休市 / ●加班中 / 休市（周末），
  午休数字暂停，下班后按倍率继续跳
- **三种计薪口径**：月薪、年薪总包、日薪
- **下班倒计时**：最后一小时自动变红；加班时显示「已加班 · ×倍率」
- **桌面悬浮窗（Electron）**：无边框置顶小窗常驻桌面，可拖动、记忆位置、
  关闭缩进系统托盘，与浏览器互不相干
- **纯前端、零依赖部署**：静态文件随处可放，配置只存浏览器 localStorage，
  无账号、无后端、数据不出本机

## 计薪方式

```
每秒费率 = 薪资 ÷ 折算秒数
```

| 口径 | 折算方式 |
|---|---|
| 月薪 | 月薪 ÷ 21.75 天（劳社部月计薪天数）÷ 每日有效工时 |
| 年薪总包 | 年薪 ÷ 261 天（21.75 × 12）÷ 每日有效工时 |
| 日薪 | 日薪 ÷ 每日有效工时 |

口径细节：只统计周一至周五；午休时段不计薪；下班后按加班倍率
（默认 1.5，可调）单独计入「今日加班费」。

## 使用

```bash
npm install
npm run dev           # 网页开发预览
npm run test          # 运行 34 个单元测试
npm run build         # 产出 dist/ 纯静态文件

npm run electron:dev  # 桌面悬浮窗开发（vite + electron 一条命令）
npm run smoke         # 构建 + Electron 冒烟截图（.impeccable/review/）
npm run dist:win      # 打包 Windows NSIS 安装包（release/）
```

把 `dist/` 扔到任意静态托管（GitHub Pages、Nginx、对象存储）即可，
或者本地直接打开 `dist/index.html`。首次打开会引导填写计薪模式和作息时间，
之后配置自动保存在浏览器里。

桌面悬浮窗：安装 `release/` 里的安装包后从桌面快捷方式启动；悬浮窗与网页
的配置各自独立存储（localStorage 按 origin 隔离），首次使用需在悬浮窗里
设置一次。

## 技术栈

Vite + Vue 3 (`<script setup>`) + TypeScript + vitest。
核心计算是无副作用的纯函数（`src/lib/calc/`），金额按绝对时间推导而非
页面累加——关页面、改系统时间、换设备都不会让数字漂移。
