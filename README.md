# 薪资跳动 (Salary Pulse)

给打工人的实时赚钱计数器：上班时间打开，「今日已赚」像水电表滚轮一样，
一秒一秒往上涨。

- **网页版**：纯静态文件，浏览器打开即用
- **桌面悬浮窗**：无边框置顶小窗常驻桌面，开着网页都省了

![截图](docs/screenshot.png)

## 特性

- **滚轮计数器**：每个数位独立滚动的机械字轮，金额每 250ms 跳一次，
  进位时正向滚满一圈，绝不倒转
- **行情状态机**：未开盘 / ●交易中 / 午间休市 / ●加班中 / 休市（周末），
  午休数字暂停，下班后按倍率继续跳
- **三种计薪口径**：月薪、年薪总包、日薪，下拉选作息，逐字段校验
- **下班倒计时**：最后一小时自动变红；加班时显示「已加班 · ×倍率」
- **周末计薪可开**：周末加班不一定按加班算——独立倍率，默认按正常薪资
- **桌面悬浮窗（Electron）**：始终置顶、整卡拖动、位置记忆、关闭缩进
  系统托盘、开机自启可选；与浏览器互不相干
- **隐私**：无账号、无后端、无埋点，薪资只存在本机

## 计薪方式

```
每秒费率 = 薪资 ÷ 折算秒数
```

| 口径 | 折算方式 |
|---|---|
| 月薪 | 月薪 ÷ 21.75 天（劳社部月计薪天数）÷ 每日有效工时 |
| 年薪总包 | 年薪 ÷ 261 天（21.75 × 12）÷ 每日有效工时 |
| 日薪 | 日薪 ÷ 每日有效工时 |

口径细节：周一至周五计薪，午休不计；周末默认休市，开了「周末也计薪」后
按同一份作息以独立倍率计（默认 ×1 正常薪资，不叠加加班倍率，下班后不累计）；
工作日下班后按加班倍率（默认 1.5，可调）单独计入「今日加班费」。

金额按绝对时间**推导**而非页面累加——关页面、改系统时间、换设备，
数字都不会漂移。

## 使用

### 网页版

把 `dist/` 扔到任意静态托管（GitHub Pages、Nginx、对象存储），或本地直接
打开 `dist/index.html`。首次打开引导填写计薪模式和作息，配置自动保存在
浏览器里。

### 桌面悬浮窗

运行 `release/` 里的安装包（`薪资跳动 Setup x.x.exe`），装完从桌面快捷
方式启动。悬浮窗和网页的配置各自独立存储，首次使用需设置一次。

托盘菜单：显示/隐藏悬浮窗、设置、开机自启、退出。点悬浮窗的 × 只是
收进托盘，不退出。

## 开发

```bash
npm install
npm run dev           # 网页开发预览
npm run electron:dev  # 桌面悬浮窗开发（vite + electron 一条命令）
npm run test          # 运行 43 个单元测试
npm run build         # 产出 dist/ 纯静态文件
npm run smoke         # 构建 + Electron 冒烟截图（.impeccable/review/）
npm run dist:win      # 打包 Windows NSIS 安装包（release/）
```

## 技术栈

Vite + Vue 3 (`<script setup>`) + TypeScript + vitest + Electron。
无 UI 组件库，样式是原生 CSS 令牌；无路由，网页用 v-if 切换视图，
三种形态（主页 / `#widget` 悬浮窗 / `#settings` 设置窗）靠 URL hash 分发。

核心计算是无副作用的纯函数（`src/lib/calc/`），30+ 单元测试覆盖；
Electron 主进程与渲染层只通过一个极小的 preload 桥接通信
（`window.salaryNative`），纯浏览器环境下该桥接不存在，互不影响。
